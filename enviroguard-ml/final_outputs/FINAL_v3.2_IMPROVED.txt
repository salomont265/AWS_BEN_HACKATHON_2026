                         🎓 KEY LESSONS LEARNED
================================================================================

1. ✅ GRADIENT BOOSTING > PROPHET for Small Datasets
   - AQI: 69 days → Prophet 58%, GB 73.7%
   - Better handles limited data

2. ✅ LAG FEATURES ARE GOLD
   - Pollen_lag24 = 59.9% feature importance
   - Historical values are best predictors

3. ✅ ROLLING AVERAGES SMOOTH NOISE
   - 3-day and 7-day averages captured trends
   - Reduced overfitting on small datasets

4. ✅ SEASONAL ENCODING MATTERS
   - Cyclical sin/cos encoding for month/day_of_year
   - Captured seasonal patterns for pollen

5. ✅ MODEL ARCHITECTURE > DATA SOURCE (Sometimes)
   - Pollen: Synthetic data but 88.3% with right model
   - Noise: Real data + simple model = 96.7%
